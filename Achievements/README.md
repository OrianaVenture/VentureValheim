## Features

This mod removes the "IsModded", and "IsWorldCheated" checks used in deciding if achievements are allowed. Allows you to avoid using that ``yesiuseddevcommandsbutiwantmyachievementsanyway`` vanilla command, which enables achievements on your cheated characters. Upon launching with this mod it removes the flag from your profile if you had this previously enabled.

You will not get achievements when using your cheated testing characters. If you desire to always get achievements even when cheating use the vanilla command mentioned above or find another mod!

## Installation

This mod is client side only and has no configuration options. Does not need to be on the server.
