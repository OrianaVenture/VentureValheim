# Venture Pride

Created by [OrianaVentureMod@gmail.com](https://github.com/OrianaVenture/VentureValheim).

## Introduction

Adds some pride themes to the game! Changes the appearance of the wooden round shield, red/white/blue banner, and ship sails! Originally made for the [Rainbow Shield Wall Charity Event](https://www.rainbowshieldwall.org)!

## Features

Each change can be toggled on or off in the mod configuration file (launch the game once to generate it). To use the trans flag for sails ensure ``ReplaceSailsRainbow`` is set to false. To disable sail changes both sail configurations must be set to false.

## Installation

This mod is client side and changes made to the configurations will only affect your client. Live updates to the configs will take immediate effect except for ship sail changes. For best results change configurations before launching a world. Must have Jotunn installed for this mod to work.
